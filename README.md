# aMazeGen
 
A maze generator covering multiple algorithms for both generation and solution that employs MatPlotLib to visualize them 

The primary goal of this project was to learn Python. To do this I decided to work with mazes and come up with a creative way to compare the methods of solving them

# Features

### This is currently a work in progress

### Planned

+ Simple IO to select
    - Width x Height
    - Generation Method
    - Solution Method
    - Option to animate
    - Ability to pause animation

+ Implement 3 generation algorithms
    - Wilson's
    - Prim's
    - Eller's

+ Implement 3 solution algorithms
    - BFS
    - DFS
    - Best 

+ Visualize both of these processes
    - Draw the maze using TKinter (MatPlotLib too slow)
    - Animate the generation
    - Animate the solution
